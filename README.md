# 🧹 FolderFixer

**Messy Desktop? Fixed in One Click.**
散らかったデスクトップやダウンロードフォルダを、ワンクリックで整理整頓するツール。

![Icon](favicon.ico)

## 🚀 Features (機能)
- **One-Click Sort / ワンクリック整理**
  - Automatically sorts images, videos, docs, and installers into folders.
  - 画像、動画、書類、インストーラーなどを自動でフォルダ分けします。

- **Safe & Secure / 安全設計**
  - Moves files only. Never deletes your data. Handles duplicate filenames automatically.
  - ファイルは「移動」するだけ。削除は一切しません。同名のファイルがあっても自動でリネームして保存します。

- **Modern UI / 高画質UI**
  - Simple design with High-DPI (Retina) support.
  - Windows 11ライクなデザインと高解像度アイコンに対応。
